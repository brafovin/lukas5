# Modemarke – Shop-Prototyp

Statischer Prototyp (HTML/CSS/JS, keine Abhängigkeiten) in `shop/`.
Öffnen: `shop/index.html` im Browser oder `python3 -m http.server -d shop`.

- Markenname: `BRAND` in `shop/app.js` (und Titel in `index.html`)
- Produkte: Liste `PRODUCTS` in `shop/app.js`
- Filter nach Jahreszeit, Größenwahl, Warenkorb (localStorage). Kasse ist eine Demo.
